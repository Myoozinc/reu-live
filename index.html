Guía Paso a Paso: Git & Vercel

1

Subir los archivos a GitHub

Tu repositorio https://github.com/Myoozinc/reu-live.git está creado pero actualmente está vacío. Copia y ejecuta estos comandos en tu terminal:

git init
git add .
git commit -m "feat: Initial ReuLive application release"
git branch -M main
git remote add origin https://github.com/Myoozinc/reu-live.git
git push -u origin main
2

Desplegar automáticamente en Vercel

Una vez completado el git push, regresa a la pestaña de Vercel y haz clic en "Deploy" o recarga la página. Vercel detectará los archivos y creará tu enlace web público en segundos.
